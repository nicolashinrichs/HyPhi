# Quickstart

The user-facing quickstart is a marimo notebook at
[`tutorials/01_quickstart.py`](https://github.com/nicolashinrichs/HyPhi/blob/main/tutorials/01_quickstart.py)
in the repository.  It walks through the canonical HyPhi workflow on a small shipped
Kuramoto connectome: config, adjacency loading, Forman-Ricci curvature, entropy,
and a basic network plot.

Run it locally with:

```shell
make tutorial
```
