# HyPhi(Φ)

A Python package for hyperscanning data analysis by tracking inter-brain network curvature
and its entropy distribution.

## Quick links

- [Quickstart tutorial](tutorials/quickstart.md)
- [Forman-Ricci examples](tutorials/frc-examples.md)
- [API reference](api/modeling.md)
- [Contributing](contributing.md)

## Install

```shell
uv sync --extra develop --extra notebook
```

Optional extras: `experiments`, `viz`, `docs`.

For an end-to-end overview see the project [README on GitHub](https://github.com/nicolashinrichs/HyPhi/).
